## Overview

This is a minimal, modern, and responsive portfolio built with the latest web technologies. It includes:

- Portfolio showcase
- Component registry for reusable UI elements (coming soon)
- SEO & PWA support

---

## Live Site

Check it out: [krup.portfolio](https://krupkantesariya-portfolio.vercel.app/)

---

## Tech Stack

- **Framework:** Next.js 15 + TypeScript
- **Styling:** Tailwind CSS v4
- **Deployment:** Vercel
- **Icons:** Lucide
- **Animations:** Framer Motion

---

## Features

- **Clean & Modern Design**
- **SEO Optimized**
- **PWA Ready**
- **Dynamic OG Images**: For rich social previews
- **Component Registry**: Easily showcase and document reusable components

---

## Development

To run locally:

```bash
# Clone the repo
git clone https://github.com/krup003/krup.portfolio.git
cd krup.portfolio

# Install dependencies
npm install


# Run development server
npm run dev
```
